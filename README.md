# GNutriElev Nutricionista

Landing page para nutricionista, com foco em credibilidade, apresentação premium e agendamento via WhatsApp.

## Como executar

1. Instale as dependências com `npm install`
2. Configure a variável `GEMINI_API_KEY` no arquivo `.env.local`
3. Inicie o projeto com `npm run dev`

## Build

- `npm run build`
- `npm run preview`
